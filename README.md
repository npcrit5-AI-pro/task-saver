# Task Saver - Simple Browser-Based To-Do App

A lightweight, browser-based **to-do list application** that allows users to **add, complete, and delete tasks**. Tasks are stored in `localStorage` so they **persist after page refresh**. The app is built with **vanilla HTML, CSS, and JavaScript** and features a clean, minimalist interface.

---

## Features

- **Add tasks** – Quickly add new tasks via the input field or by pressing Enter.
- **Mark tasks as complete** – Click on a task to toggle its completed status.
- **Delete tasks** – Remove tasks with a single click.
- **Persistent storage** – All tasks are saved using `localStorage` and remain after refresh.
- **Keyboard support** – Press Enter to add tasks without clicking the button.
- **Clean interface** – Minimal, modern design that’s easy to use.

---

## How to Use

1. Clone the repository or download the `index.html` file.
2. Open `index.html` in your browser.
3. Start adding tasks using the input field.
4. Click a task to mark it complete or press the **Delete** button to remove it.
5. Your tasks will be saved automatically and remain after refresh.
